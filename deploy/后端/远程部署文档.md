## 4. 问题记录

| 序号 | 清单编号 | 问题描述 | 解决方式 | 状态 |
|------|----------|----------|----------|------|
| 1 | ENV-005/006/007 | 默认端口 8080/3306/6379 被服务器上其他项目(ticket-system, ai-dev)占用 | docker-compose.yml 端口映射调整为 8082/3307/6381 | 已解决 |
| 2 | DB-004 | MySQL JDBC 8.3.0 不支持 `characterEncoding=utf8mb4`，启动时报 `Unsupported character encoding 'utf8mb4'` | 将 SPRING_DATASOURCE_URL 中 `characterEncoding=utf8mb4` 修改为 `characterEncoding=UTF-8` | 已解决 |

## 5. 回滚方案

### 回滚触发条件
- 后端 API 持续返回 5xx 错误
- 数据库连接持续失败
- 容器反复崩溃重启

### 回滚命令/步骤

```bash
ssh -p 22 root@10.32.129.153

cd /opt/deploy/questionnaire-backend

# 停止并移除所有容器
docker-compose down

# 移除构建的镜像
docker rmi questionnaire-backend-app:latest

# 数据卷保留（如需清除数据加 -v 参数）
# docker-compose down -v  # 警告：会删除MySQL数据
```

### 回滚验证
```bash
docker-compose ps   # 应显示无运行容器
curl http://localhost:8082   # 应返回 connection refused
```

### 数据库回滚
- MySQL 数据存储在 Docker Volume `questionnaire-backend_mysql-data` 中
- 如需彻底清除: `docker volume rm questionnaire-backend_mysql-data`
- 如需保留数据后重新部署: 保留 volume，重新 `docker-compose up -d --build`
