## 一、添加题目（FR-016）

### TC-QS-001: 添加单选题 - 正常流程
- **关联需求**: FR-016
- **前置条件**: 
  1. 已通过 `POST /api/login` 登录获取accessToken
  2. 已存在一份问卷（通过 `POST /api/questionnaires` 创建），记录问卷ID为 `{qnrId}`，问卷状态为草稿
- **测试步骤**:
  1. 发送请求:
     - **Method**: POST
     - **URL**: `http://10.32.129.153:8082/api/questionnaires/{qnrId}/questions`
     - **Headers**: `Content-Type: application/json`, `Authorization: Bearer {accessToken}`
     - **Body**:
       ```json
       {
         "type": "radio",
         "title": "您的性别是？",
         "required": true,
         "options": [
           {"content": "男"},
           {"content": "女"},
           {"content": "保密"}
         ]
       }
       ```
  2. 验证响应状态码和响应体
  3. 发送 `GET /api/questionnaires/{qnrId}` 查询问卷详情，验证题目已添加
- **预期结果**:
  - HTTP状态码: `200`
  - 响应体包含字段: `id`（题目ID，非空）、`type` 值为 `"radio"`、`title` 值为 `"您的性别是？"`、`required` 值为 `true`
  - 响应体 `options` 数组长度为3，每项包含 `id` 和 `content` 字段
  - 查询问卷详情时，`questions` 数组中包含该题目
- **优先级**: P0
- **测试类型**: 正常流程
