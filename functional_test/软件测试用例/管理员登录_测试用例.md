# 管理员登录模块 - 测试用例

## 测试环境信息
- **测试地址**: http://10.32.129.153:3002
- **默认测试账号**: admin / admin123
- **登录页路由**: /login
- **技术栈**: Vue 3 + Element Plus + Pinia

---

## TC-LOGIN-001: 正确账号密码登录成功
- **关联需求**: FR-001
- **前置条件**: 
  - 用户未登录
  - 测试账号 admin/admin123 可用
- **测试步骤**:
  1. 访问登录页 http://10.32.129.153:3002/login
  2. 在用户名输入框输入 "admin"
  3. 在密码输入框输入 "admin123"
  4. 点击登录按钮
- **预期结果**: 
  - 登录成功，页面跳转至 /dashboard
  - localStorage 中存储 accessToken 和 refreshToken
- **优先级**: P0
- **测试类型**: 正常流程

## TC-LOGIN-017: Token 过期后自动刷新
- **关联需求**: FR-009
- **前置条件**: 
  - 用户已登录
  - accessToken 即将过期或已过期
- **测试步骤**:
  1. 使用 admin/admin123 登录系统
  2. 等待 accessToken 过期（或手动修改 localStorage 中 Token 的过期时间）
  3. 在后台页面执行任意需要认证的操作（如访问问卷列表）
  4. 打开浏览器开发者工具 Network 面板观察请求
- **预期结果**: 
  - 自动调用 /auth/refresh 接口刷新 Token
  - 刷新成功后，原请求自动重试并成功
  - 用户无感知，页面正常显示数据
  - localStorage 中 Token 已更新
- **优先级**: P0
- **测试类型**: 正常流程
