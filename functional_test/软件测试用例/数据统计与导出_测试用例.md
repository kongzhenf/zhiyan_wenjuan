## 一、统计概览（FR-036）

### TC-STAT-001: 获取统计概览-完整数据
- **关联需求**: FR-036
- **前置条件**: 已登录获取有效accessToken；存在已发布的问卷（questionnaireId=1），且该问卷已有至少1条回收数据
- **测试步骤**:
  1. 发送请求获取统计概览:
     ```
     GET http://10.32.129.153:8082/api/statistics/1/overview
     Headers:
       Authorization: Bearer {accessToken}
       Content-Type: application/json
     ```
  2. 检查响应状态码和响应体结构
- **预期结果**:
  - HTTP状态码: 200
  - 响应体包含以下关键字段:
    - `code` = 0（或业务成功码）
    - `data.totalCount` >= 1（总回收量，整数类型）
    - `data.todayCount` >= 0（今日新增，整数类型）
    - `data.validRate` 为数值类型且范围在 0~100 之间（有效回收率）
    - `data.trend` 为数组类型，包含时间趋势数据，每项含日期和计数字段
- **优先级**: P0
- **测试类型**: 正常流程

## 二、逐题统计（FR-037）

### TC-STAT-004: 逐题统计-选择题选项占比
- **关联需求**: FR-037
- **前置条件**: 已登录获取有效accessToken；问卷（questionnaireId=1）包含选择题（单选/多选），且已有回收数据
- **测试步骤**:
  1. 发送请求获取逐题统计:
     ```
     GET http://10.32.129.153:8082/api/statistics/1/questions
     Headers:
       Authorization: Bearer {accessToken}
       Content-Type: application/json
     ```
  2. 在返回的题目统计列表中，找到选择题的统计数据
  3. 验证选项占比字段
- **预期结果**:
  - HTTP状态码: 200
  - 响应体 `data` 为数组，每项包含:
    - `questionId`（题目ID）
    - `questionType`（题目类型）
    - 选择题项包含 `options` 数组，每个选项含 `label`（选项文本）、`count`（选择次数，整数）、`percentage`（占比，数值类型 0~100）
    - 所有选项的 `percentage` 之和约等于100（单选题）或各选项独立计算（多选题）
- **优先级**: P0
- **测试类型**: 正常流程
