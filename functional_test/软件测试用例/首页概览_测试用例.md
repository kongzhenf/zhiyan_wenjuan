### TC-DASH-001 统计卡片正常展示四项指标

- **关联需求：** FR-011
- **优先级：** P0
- **测试类型：** 功能测试
- **前置条件：**
  - 使用 admin/admin123 登录管理后台
  - 系统中已存在问卷数据（问卷总数 > 0）
  - `getStatisticsOverviewApi` 接口正常返回数据

**测试步骤：**

1. 打开浏览器，访问 http://10.32.129.153:3002
2. 使用 admin / admin123 登录
3. 登录成功后跳转至首页 `/dashboard`
4. 等待页面完全加载（loading 消失）
5. 观察页面顶部统计卡片区域

**预期结果：**

- 页面顶部显示 4 个统计卡片，分别为：问卷总数、进行中、总回收量、今日新增
- 每个卡片均有对应的数字数值，数值类型为非负整数
- 4 个卡片全部可见，无遮挡、无排版错乱

### TC-DASH-002 统计卡片数据与后端接口一致性验证

- **关联需求：** FR-011
- **优先级：** P0
- **测试类型：** 功能测试
- **前置条件：**
  - 使用 admin/admin123 登录管理后台
  - 已知当前系统中问卷总数、进行中数量、总回收量、今日新增的准确值（可通过数据库或其他接口确认）

**测试步骤：**

1. 打开浏览器开发者工具，切换至 Network 面板
2. 访问 http://10.32.129.153:3002 并登录
3. 进入首页 `/dashboard`，等待页面加载完成
4. 在 Network 面板中找到 `getStatisticsOverviewApi` 的请求，查看响应数据
5. 对比页面上四个卡片的数值与接口响应中对应字段的值

**预期结果：**

- 页面"问卷总数"卡片数值与接口返回的问卷总数字段一致
- 页面"进行中"卡片数值与接口返回的进行中数量字段一致
- 页面"总回收量"卡片数值与接口返回的总回收量字段一致
- 页面"今日新增"卡片数值与接口返回的今日新增字段一致

### TC-DASH-003 统计接口异常时卡片的降级展示

- **关联需求：** FR-011
- **优先级：** P1
- **测试类型：** 异常测试
- **前置条件：**
  - 使用 admin/admin123 登录管理后台
  - 可通过断网、Mock 工具或后端配合模拟 `getStatisticsOverviewApi` 返回 5xx 错误

**测试步骤：**

1. 使用浏览器开发者工具中的 Network 面板，将 `getStatisticsOverviewApi` 请求拦截或屏蔽（block request URL）
2. 访问 http://10.32.129.153:3002 并登录
3. 进入首页 `/dashboard`，等待请求失败
4. 观察统计卡片区域的展示状态

**预期结果：**

- 页面不崩溃、不出现白屏
- 统计卡片区域显示 0 或占位符（"-"），不展示错误堆栈信息
- 可选：页面给出友好的错误提示（如"数据加载失败"）

### TC-DASH-016 页面初始加载时出现 loading 状态

- **关联需求：** FR-011
- **优先级：** P1
- **测试类型：** 功能测试
- **前置条件：**
  - 使用 admin/admin123 登录管理后台
  - 网络正常（非断网场景）

**测试步骤：**

1. 打开浏览器开发者工具，切换至 Network 面板，将网络限速设置为 Slow 3G（模拟慢速网络）
2. 访问 http://10.32.129.153:3002 并登录
3. 导航至首页 `/dashboard`
4. 在数据返回前，立即观察页面的加载状态
5. 等待接口全部返回后，再次观察页面状态

**预期结果：**

- 数据返回前，页面显示 loading 状态（如骨架屏、加载动画或 Element Plus 的 `v-loading` 指令效果）
- 数据返回后，loading 状态消失，内容正常展示
- 整个过程中页面不出现白屏或 JS 报错
