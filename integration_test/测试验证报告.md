## 3. 关键业务流程端到端验证

### 3.1 问卷创建→发布→填写→统计 完整流程

```
步骤1: POST /api/auth/login → 获取管理员Token ✅
步骤2: POST /api/questionnaires → 创建问卷(id=4) ✅
步骤3: POST /api/questionnaires/4/questions → 添加单选题 ✅
步骤4: POST /api/questionnaires/4/publish → 发布问卷，获取填写链接 ✅
步骤5: GET /api/fill/{linkId} → H5端获取问卷(无需认证) ✅
步骤6: POST /api/fill/{linkId}/submit → 用户提交答案 ✅
步骤7: GET /api/statistics/1/overview → 统计数据更新(totalResponses=3) ✅
步骤8: POST /api/statistics/1/export → 导出数据为xlsx ✅
步骤9: GET /api/statistics/exports/{id}/download → 下载导出文件 ✅
```

**结论**: 核心业务流程从问卷创建到数据导出，全链路验证通过。

### 3.2 nginx 反向代理链路验证

```
前端浏览器 → questionnaire-frontend:80 (nginx)
  ├── 静态文件请求 → /usr/share/nginx/html (Vue 构建产物)
  ├── /api/* 请求 → proxy_pass http://backend:8080/api/
  └── 其他路径 → try_files → /index.html (SPA 路由)

H5浏览器 → questionnaire-h5:80 (nginx)
  ├── 静态文件请求 → /usr/share/nginx/html (Vue 构建产物)
  ├── /api/* 请求 → proxy_pass http://backend:8080/api/
  └── 其他路径 → try_files → /index.html (SPA 路由)
```

**验证结果**: 
- 前端 nginx → backend 代理：✅ 正常（TC-013）
- H5 nginx → backend 代理：✅ 正常（TC-015）
- SPA 路由 fallback：✅ 正常（TC-028, TC-029）
- 无 502 Bad Gateway 错误
